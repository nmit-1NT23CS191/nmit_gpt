# Campus Public Portal

This is the public-facing portal for campus events, updates, and the assistant experience.

## Purpose
- Event feed for campus visitors
- Public assistant/chat experience
- No authentication barrier for ordinary users

## Local development

From the workspace root:

```bash
cd campus-rag-platform/frontend
npm run dev
```

Open:
- Public app: http://localhost:3000

The admin app remains isolated on port 3001 and is protected by the auth wall.
